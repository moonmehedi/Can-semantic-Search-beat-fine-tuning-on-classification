# Publication Venues for BPDQAC Paper

Paper reviewed: `A question-and-answer classification dataset for borderline personality disorder screening`

Verified online: April 22, 2026

## Notes

- This paper is best positioned as a clinically annotated mental health NLP dataset paper with transformer baselines.
- Conferences usually do not have Impact Factor or Q1/Q2 in the same way journals do, so the conference table focuses on indexing, scope, and submission fit.

## My Short Recommendation

- Best conference in Bangladesh: **IEEE BECITHCON 2026**
- Best journal if the dataset is publicly archived properly: **Scientific Data**
- Best realistic journal targets if not aiming for a pure data-descriptor route: **Journal of Biomedical Informatics** and **BMC Medical Informatics and Decision Making**

## Submission Risks to Fix Before Sending

- The data availability section in `main.tex` still contains placeholders for repository name and link.
- The paper mentions written informed consent, but an explicit IRB/ethics approval statement is not clearly visible in the current draft.
- For top dataset journals, public release of the dataset with a stable repository link or DOI will matter a lot.
